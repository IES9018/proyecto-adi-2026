# Ejercicio 01: Entrevista con el Arquitecto

## Objetivo

Aprender a comunicar tu idea de proyecto al agente Arquitecto de forma clara y estructurada.

## Prompt (copiá y pegá en tu terminal de IA)

```text
Soy estudiante de Arquitectura y Diseño de Interfaces y necesito
definir un proyecto para aplicar el andamiaje de agentes IA.

Actuá como un Arquitecto de Software Senior. Tu tarea es
entrevistarme para ayudarme a definir mi proyecto.

Hacé las siguientes preguntas DE A UNA POR VEZ (esperá mi respuesta):

1. ¿Qué problema querés resolver con este sistema?
2. ¿Quiénes van a ser los usuarios principales?
3. ¿Cuáles son las 3 funcionalidades más importantes?
4. ¿Qué NO debería hacer el sistema?
5. ¿Qué tecnología preferís? (web, mobile, escritorio)
6. ¿Necesita base de datos?
7. ¿Cuánto tiempo tenés para desarrollarlo?

Después de mis respuestas, proponé 2 o 3 opciones de proyecto
con nombre y descripción breve. Ayudame a elegir la mejor.
```

## Lo que aprendés haciendo esto

- A pensar en términos de **problema y solución**, no de funcionalidades sueltas
- A **delimitar el alcance**: decir "no" a funcionalidades que no corresponden
- A identificar **usuarios y roles** antes de pensar en código

## Entrega

Después de la conversación con el agente:

1. Creá la carpeta `00_REFERENCIAS/` en tu repo
2. Guardá la conversación en `00_REFERENCIAS/entrevista-inicial.md`
3. Incluí el nombre definitivo del proyecto y el objetivo principal
4. Commit: `git commit -m "feat: completa ejercicio 01 - entrevista con arquitecto"`
5. Creá un PR con la rama `feat/ej-01-entrevista`

## Criterios de aprobación

- [ ] Definiste un nombre de proyecto concreto
- [ ] Identificaste al menos 2 tipos de usuarios
- [ ] Listaste 3 funcionalidades principales
- [ ] Definiste qué NO hace el sistema
- [ ] Elegiste tipo de aplicación (web, mobile, etc.)
