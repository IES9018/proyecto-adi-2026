# Ejercicios Prácticos — Arquitectura y Diseño de Interfaces

Cada ejercicio consiste en un **prompt listo para copiar y pegar** en tu terminal de IA (opencode, gemini-cli, etc.), más una **consigna de entrega** para tu repositorio.

---

## 🎯 Cómo usar estos ejercicios

| Paso | Qué hacer |
|:-----|:----------|
| 1 | Leé el ejercicio completo antes de empezar |
| 2 | Copiá el prompt en tu terminal de IA |
| 3 | Respondé a las preguntas que la IA te haga |
| 4 | Cuando termines, guardá el resultado en tu repo |
| 5 | Creá un PR para que el docente lo revise |

**Regla:** No avances al siguiente ejercicio sin que el anterior esté aprobado.

---

## 🗺️ Recorrido Pedagógico

Los ejercicios siguen el ciclo natural del desarrollo de software:

```
Clase 1:  Ej 1 (Scoping) → Ej 2 (C4 Contexto)
Clase 2:  Ej 3 (ADR) → profundizás arquitectura
Clase 3:  Ej 4 (Modelo de Dominio) → Ej 5 (Wireframe)
Clase 4+: Ej 6 (Defensa Oral) — práctica para el final
```

> Estos ejercicios están diseñados para que los hagas **en orden**. Cada uno construye sobre el anterior.

Tus entregas de ejercicios se hacen en **tu repositorio personal** (el mismo de tu proyecto), no en el repo de la organización. Cada ejercicio es un PR.
